API Endpoints
Method Path 설명 모듈 Auth
POST /api/auth/register 회원가입 auth 🔓 Public
POST /api/auth/login 로그인 → JWT 반환 auth 🔓 Public
GET /api/users/me 내 프로필 조회 user 🔒 JWT
GET /api/voca/books 단어장 목록 voca 🔒 JWT
GET /api/voca/books/{id}/days/{day}/words Day별 단어 목록 voca 🔒 JWT
POST /api/writing/essays 에세이 저장 writing 🔒 JWT
GET /api/writing/essays 내 에세이 목록 writing 🔒 JWT
POST /api/writing/essays/{id}/correction Claude AI 교정 요청 writing 🔒 JWT
GET /api/reading/books 지문 라이브러리 reading 🔒 JWT
GET /api/reading/books/{id} 지문 상세 조회 reading 🔒 JWT
GET /api/conversation/topics 토픽 목록 conv 🔒 JWT
POST /api/conversation/sessions 대화 세션 시작 conv 🔒 JWT
